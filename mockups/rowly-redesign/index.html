What it supports today

A focused desktop client for common relational database work. The code and current release confirm these engines and platforms.

PostgreSQL

Tested in the repository against versions 13 through 18.

MySQL

Tested against MySQL 8.0, 8.4, and 9.7.

MariaDB

A separate engine profile with its own SQL dialect behavior.

Desktop packages

Windows installers, macOS DMGs, and Linux AppImage, DEB, RPM, and Arch packages.
