macOS

Suggested

Pick the chip your Mac has. Apple menu → About This Mac shows it.

  • Apple SiliconM-series chip · .dmg
  • Intelx64 · .dmg

Not notarized by Apple yet, so macOS blocks the first launch. Open System Settings → Privacy & Security and choose Open Anyway.

Windows

Suggested

Windows 10 or 11, 64-bit.

  • Installerx64 · .exe · recommended
  • MSI packagex64 · .msi · managed installs

Not code-signed yet. If SmartScreen says “Windows protected your PC”, choose More info → Run anyway. If WebView2 is missing, the installer downloads it.

Linux

Suggested

x86_64. Needs WebKitGTK 4.1, which your package manager installs.

  • Debian, Ubuntux86_64 · .deb
  • Fedorax86_64 · .rpm
  • Arch Linuxx86_64 · .pkg.tar.zst
  • AppImagex86_64 · .AppImage · no install

No ARM builds yet. Updates come from the app, not from your package manager.

Install from the terminal (Linux)

Debian, Ubuntu (apt)

curl -LO https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/Rowly.DB_{{version}}_amd64.deb
sudo apt install ./Rowly.DB_{{version}}_amd64.deb

apt installs the libraries it needs.

Fedora (dnf)

sudo dnf install https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/Rowly.DB-{{version}}-1.x86_64.rpm

dnf downloads the package and its dependencies.

Arch Linux (pacman)

curl -LO https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/rowly-db_{{version}}_x86_64.pkg.tar.zst
sudo pacman -U ./rowly-db_{{version}}_x86_64.pkg.tar.zst

pacman installs the libraries it needs.

AppImage

curl -LO https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/Rowly.DB_{{version}}_amd64.AppImage
chmod +x Rowly.DB_{{version}}_amd64.AppImage
./Rowly.DB_{{version}}_amd64.AppImage

Nothing to install. Keep the file wherever you want to run it from.

Already installed? New versions arrive in Settings → Updates, and update packages are signed. You can also build it from source.
