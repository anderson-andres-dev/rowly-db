Edit results, read the SQL, then apply

Changes made in the result grid are not written right away. Rowly DB turns them into statements and shows them first.

  • DELETE removed rows
  • UPDATE edited cells
  • INSERT new rows

  1. Edit in the grid

    Change cells, add rows with Ctrl I, mark rows with Ctrl Delete.

  2. Review the statements

    Each change becomes an INSERT, UPDATE or DELETE you can read before it runs.

  3. Apply

    The statements run together. If one fails, none is applied. On production connections, every write asks for confirmation.

An editor that reads your schema

Suggestions and warnings come from the tables, columns and foreign keys of the connected database.

  • Ctrl Enter runs the statement under the cursor
  • Ctrl L formats the SQL

Consoles, results and a terminal

Put consoles and result tabs side by side, and open a shell in the connection's SQL folder.

Windows

Your system

Windows 10 or 11, x64.

  • Installer.exe
  • MSI package.msi, for managed installs

Not code-signed. If SmartScreen says "Windows protected your PC", choose More info → Run anyway. If WebView2 is missing, the installer downloads it.

macOS

Your system

Apple menu → About This Mac shows your chip.

  • Apple Silicon.dmg
  • Intel.dmg

Not notarized by Apple, so macOS blocks the first launch. Open System Settings → Privacy & Security and choose Open Anyway.

Linux

Your system

x86_64 with WebKitGTK 4.1, which your package manager installs.

  • Debian, Ubuntu.deb
  • Fedora.rpm
  • Arch Linux.pkg.tar.zst
  • AppImage.AppImage, no install

No ARM builds. Updates come from the app, not from your package manager.

Install from the terminal (Linux)

Debian, Ubuntu (apt)

curl -LO https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/Rowly.DB_{{version}}_amd64.deb
sudo apt install ./Rowly.DB_{{version}}_amd64.deb

apt installs the libraries it needs.

Fedora (dnf)

sudo dnf install https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/Rowly.DB-{{version}}-1.x86_64.rpm

dnf downloads the package and its dependencies.

Arch Linux (pacman)

curl -LO https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/rowly-db_{{version}}_x86_64.pkg.tar.zst
sudo pacman -U ./rowly-db_{{version}}_x86_64.pkg.tar.zst

pacman installs the libraries it needs.

AppImage

curl -LO https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/Rowly.DB_{{version}}_amd64.AppImage
chmod +x Rowly.DB_{{version}}_amd64.AppImage
./Rowly.DB_{{version}}_amd64.AppImage

Nothing to install. Keep the file wherever you want to run it from.

Already installed? New versions arrive in Settings → Updates, and update packages are signed. You can also build it from source.

Questions

Is it free?

Yes. No account, no paid edition, and the source is public under MIT or Apache-2.0.

Why does my system warn about the installer?

The Windows installer is not code-signed and the macOS app is not notarized, so SmartScreen or Gatekeeper may stop the first launch. The steps to continue are next to each download.

How do updates work?

New versions appear in Settings → Updates and install when you choose. Update packages are signed.

Which databases does it support?

PostgreSQL, MySQL and MariaDB. New engines are tested against real servers before they are listed.
