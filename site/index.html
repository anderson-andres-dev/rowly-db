Review every change before it runs

Edit data naturally, then inspect the SQL Rowly DB will execute before applying INSERT, UPDATE, or DELETE operations.

  1. Edit resultsChange cells, add rows or mark rows for deletion in the result grid.
  2. Rowly DB writes the SQLEach change becomes an INSERT, UPDATE or DELETE statement.
  3. Review the statementsRead the exact SQL in the Pending changes dialog.
  4. Apply explicitlyNothing reaches the database until you choose Apply changes.
  • INSERT new rows
  • UPDATE edited cells
  • DELETE removed rows

On production connections, every write asks for confirmation.

Write SQL with an editor that knows your schema

Suggestions and warnings come from the tables and columns of the database you are connected to.

Edit results in place

Run a query, then change the data right where you see it. Edits stay highlighted in the grid as pending changes until you apply them.

Windows

Windows 10 or 11, 64-bit.

  • Installerx64 · .exe
  • MSI packagex64 · .msi · managed installs

Not code-signed. If SmartScreen says “Windows protected your PC”, choose More info → Run anyway. If WebView2 is missing, the installer downloads it.

macOS

Suggested for your system

Pick the chip your Mac has: Apple menu → About This Mac.

  • Apple SiliconM-series chip · .dmg
  • Intelx64 · .dmg

Not notarized by Apple, so macOS blocks the first launch. Open System Settings → Privacy & Security and choose Open Anyway.

Linux

Suggested for your system

x86_64. Needs WebKitGTK 4.1, which your package manager installs.

  • Debian, Ubuntux86_64 · .deb
  • Fedorax86_64 · .rpm
  • Arch Linuxx86_64 · .pkg.tar.zst
  • AppImagex86_64 · .AppImage · no install

There are no ARM builds. Updates come from the app, not from your package manager.

Install from the terminal (Linux)

Debian, Ubuntu (apt)

curl -LO https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/Rowly.DB_{{version}}_amd64.deb
sudo apt install ./Rowly.DB_{{version}}_amd64.deb

apt installs the libraries it needs.

Fedora (dnf)

sudo dnf install https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/Rowly.DB-{{version}}-1.x86_64.rpm

dnf downloads the package and its dependencies.

Arch Linux (pacman)

curl -LO https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/rowly-db_{{version}}_x86_64.pkg.tar.zst
sudo pacman -U ./rowly-db_{{version}}_x86_64.pkg.tar.zst

pacman installs the libraries it needs.

AppImage

curl -LO https://github.com/anderson-andres-dev/rowly-db/releases/download/v{{version}}/Rowly.DB_{{version}}_amd64.AppImage
chmod +x Rowly.DB_{{version}}_amd64.AppImage
./Rowly.DB_{{version}}_amd64.AppImage

Nothing to install. Keep the file wherever you want to run it from.

Already installed? New versions arrive in Settings → Updates, and update packages are signed. You can also build it from source.

Frequently asked questions

What is Rowly DB?

Rowly DB is a free, open-source desktop SQL client. You write queries, browse the schema, edit results in place and review every pending change as SQL before it runs.

Is Rowly DB free?

Yes, with no account to create and no paid edition.

Is Rowly DB open source?

Yes. It is dual licensed under MIT or Apache-2.0, at your choice, and the code is on GitHub.

Which databases does it support?

PostgreSQL and MySQL; other database engines are not supported.

Which operating systems does it support?

Windows 10 and 11 (64-bit), macOS on Apple Silicon and Intel, and Linux on x86_64. There are no ARM builds for Windows or Linux.

Where can I download it?

In the downloads section above, or from the latest release on GitHub.

Why does my system warn me about the installer?

The Windows installer is not code-signed and the macOS app is not notarized by Apple, so SmartScreen or Gatekeeper may stop the first launch. The steps to continue are next to each download.

How do updates work?

New versions appear in Settings → Updates and install when you choose. Update packages are signed.
